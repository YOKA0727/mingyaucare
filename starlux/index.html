設定

所有設定只存在這支手機的瀏覽器裡，不會上傳到其他地方。
自動判斷規則：抵達後 折返等待上限 內沒有回台班機 → 過夜；有折返班時估算工時（報到起飛前 1 小時 ＋ 去回飛行 ＋ 落地後 30 分），超過 工時上限 → 過夜，介於兩個門檻之間 → 不確定（兩種回程都列）。這是用公開班表推算，不等於真實組員排班。

班表（航線、班號、表定時間）每 7 天向 API 抓一次；即時狀態（延誤、登機門）每次重新整理抓 2 次。
「回程」是依航空公司公開班表自動配對的，不一定是女友實際的組員排班。
